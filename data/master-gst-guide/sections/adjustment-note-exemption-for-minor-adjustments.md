# Adjustment note exemption for minor adjustments ¶6-135

There is no requirement to issue an adjustment note if the amount of the adjustment is $75 or less (s 29-80; GST Regulations s 29-80.02).

It is irrelevant what the value of the original supply may have been.

Example The value of a taxable supply is $1,000. As a result of an adjustment event, there is a decreasing adjustment of $60. As this does not exceed the applicable $75 threshold, no adjustment note is required.

*Refs: s 29-80*
