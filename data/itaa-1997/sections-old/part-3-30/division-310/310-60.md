# 310-60  CGT assets—individual asset approach

Consequences for transferring entity

<a id="s310-60-1"></a>
**(1)**  The transferring entity may disregard any [[*capital gain*](/itaa-1997/s995-1#s995-1-capital-gain)*](/itaa-1997/s995-1#s995-1-capital-gain) or [[*capital loss*](/itaa-1997/s995-1#s995-1-capital-loss)*](/itaa-1997/s995-1#s995-1-capital-loss) for a transfer event relating to an original asset to which this section applies.

> **Note:** This section only applies if it is chosen to apply under subsection 310-50(2). 382                                  Income Tax Assessment Act 1997 Authorised Version C2026C00122 registered 10/04/2026 Specialist liability rules Chapter 3 Superannuation Part 3-30 Loss relief for merging superannuation funds Division 310 Section 310-65

<a id="s310-60-2"></a>
**(2)**  Subsections (3), (4) and (5) apply if under subsection (1) the transferring entity disregards a [[*capital gain*](/itaa-1997/s995-1#s995-1-capital-gain)*](/itaa-1997/s995-1#s995-1-capital-gain) or [[*capital loss*](/itaa-1997/s995-1#s995-1-capital-loss)*](/itaa-1997/s995-1#s995-1-capital-loss) for a transfer event relating to an original asset.

<a id="s310-60-3"></a>
**(3)**  The transferring entity’s [[*capital proceeds*](/itaa-1997/s995-1#s995-1-capital-proceeds)*](/itaa-1997/s995-1#s995-1-capital-proceeds) from the transfer event are taken to be an amount equal to:

> <a id="s310-60-3-a"></a>
> **(a)**  if, apart from this subsection, the event would result in a [[*capital gain*](/itaa-1997/s995-1#s995-1-capital-gain)*](/itaa-1997/s995-1#s995-1-capital-gain)—the asset’s [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base just before the event; or

> <a id="s310-60-3-b"></a>
> **(b)**  if, apart from this subsection, the event would result in a [[*capital loss*](/itaa-1997/s995-1#s995-1-capital-loss)*](/itaa-1997/s995-1#s995-1-capital-loss)—the asset’s *reduced cost base just before the event. Consequences for receiving entity

<a id="s310-60-4"></a>
**(4)**  The first element of the [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base of the corresponding received asset (in the hands of the receiving entity) is taken to be an amount equal to the cost base of the original asset just before the event.

<a id="s310-60-5"></a>
**(5)**  The first element of the *reduced cost base of the corresponding received asset (in the hands of the receiving entity) is taken to be an amount equal to the reduced cost base of the original asset just before the event.
