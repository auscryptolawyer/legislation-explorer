# 43-154  Notice of events


<a id="s43-154-1"></a>
**(1)**  If any of the following events happen in relation to a [[*build to rent development*](/itaa-1997/s995-1#s995-1-build-to-rent-development)*](/itaa-1997/s995-1#s995-1-build-to-rent-development), each entity to which subsection (3) applies must notify the Commissioner of the event:

> <a id="s43-154-1-a"></a>
> **(a)**  the development *commences to be an [[*active build to rent development*](/itaa-1997/s995-1#s995-1-active-build-to-rent-development)*](/itaa-1997/s995-1#s995-1-active-build-to-rent-development);

> <a id="s43-154-1-b"></a>
> **(b)**  the development *expands;

> <a id="s43-154-1-c"></a>
> **(c)**  the [[*ownership interest*](/itaa-1997/s995-1#s995-1-ownership-interest)*](/itaa-1997/s995-1#s995-1-ownership-interest) in the development is acquired by another entity;

> <a id="s43-154-1-d"></a>
> **(d)**  the development *ceases to be an active build to rent development.

<a id="s43-154-2"></a>
**(2)**  The notice must be:

> <a id="s43-154-2-a"></a>
> **(a)**  in the [[*approved form*](/itaa-1997/s995-1#s995-1-approved-form)*](/itaa-1997/s995-1#s995-1-approved-form); and

> <a id="s43-154-2-b"></a>
> **(b)**  given no later than 28 days after the event.

<a id="s43-154-3"></a>
**(3)**  This subsection applies to the following entities:

> <a id="s43-154-3-a"></a>
> **(a)**  the owner of the development at the time just before the event happens;

> <a id="s43-154-3-b"></a>
> **(b)**  if in the income year in which the event happens, an entity is required to notify the Commissioner under subsection 16-150(4) in Schedule 1 to the Taxation Administration Act 1953 of an amount to which Income Tax Assessment Act 1997                            209 Authorised Version C2026C00122 registered 10/04/2026 Section 43-154A subsection 12-450(5) in that Schedule applies, to any extent, because of a [[*dwelling*](/itaa-1997/s995-1#s995-1-dwelling)*](/itaa-1997/s995-1#s995-1-dwelling) of the development—the entity;

> <a id="s43-154-3-c"></a>
> **(c)**  if the event is the event mentioned in paragraph (1)(c) of this section—the entity that acquires the [[*ownership interest*](/itaa-1997/s995-1#s995-1-ownership-interest)*](/itaa-1997/s995-1#s995-1-ownership-interest) in the development. 43-154A References to buildings A reference in sections 43-151 to 43-153 to a building includes a reference to any other buildings that are on the same or adjacent land.
