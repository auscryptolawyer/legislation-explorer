# 202-80  Distribution statement


<a id="s202-80-1"></a>
**(1)**  A distribution statement is a statement made in accordance with this section.

<a id="s202-80-2"></a>
**(2)**  The statement must be in the [[*approved form*](/itaa-1997/s995-1#s995-1-approved-form)*](/itaa-1997/s995-1#s995-1-approved-form).

<a id="s202-80-3"></a>
**(3)**  The statement must:

> <a id="s202-80-3-a"></a>
> **(a)**  identify the entity making the distribution; and

> <a id="s202-80-3-b"></a>
> **(b)**  state the date on which the distribution is made; and

> <a id="s202-80-3-c"></a>
> **(c)**  state the amount of the distribution; and

> <a id="s202-80-3-d"></a>
> **(d)**  state that there is a [[*franking credit*](/itaa-1997/s995-1#s995-1-franking-credit)*](/itaa-1997/s995-1#s995-1-franking-credit) of an amount specified on the distribution; and

> <a id="s202-80-3-e"></a>
> **(e)**  state the [[*franking percentage*](/itaa-1997/s995-1#s995-1-franking-percentage)*](/itaa-1997/s995-1#s995-1-franking-percentage) for the distribution; and

> <a id="s202-80-3-f"></a>
> **(f)**  state the amount of any [[*withholding tax*](/itaa-1997/s995-1#s995-1-withholding-tax)*](/itaa-1997/s995-1#s995-1-withholding-tax) that has been deducted from the distribution by the entity; and

> <a id="s202-80-3-g"></a>
> **(g)**  include any other information required by the [[*approved form*](/itaa-1997/s995-1#s995-1-approved-form)*](/itaa-1997/s995-1#s995-1-approved-form) that is relevant to imputation generally or the distribution.
