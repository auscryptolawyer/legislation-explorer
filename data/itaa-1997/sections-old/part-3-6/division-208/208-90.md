# 208-90  All frankable distributions made within a franking period must be franked to the same extent with an exempting credit


<a id="s208-90-1"></a>
**(1)**  If an entity *franks a *distribution with an exempting credit, it must frank each other [[*frankable distribution*](/itaa-1997/s995-1#s995-1-frankable-distribution)*](/itaa-1997/s995-1#s995-1-frankable-distribution) made within the same [[*franking period*](/itaa-1997/s995-1#s995-1-franking-period)*](/itaa-1997/s995-1#s995-1-franking-period) with an exempting credit worked out at the same [[*exempting percentage*](/itaa-1997/s995-1#s995-1-exempting-percentage)*](/itaa-1997/s995-1#s995-1-exempting-percentage).

<a id="s208-90-2"></a>
**(2)**  If an entity is not a [[*former exempting entity*](/itaa-1997/s995-1#s995-1-former-exempting-entity)*](/itaa-1997/s995-1#s995-1-former-exempting-entity) for the whole of a [[*franking period*](/itaa-1997/s995-1#s995-1-franking-period)*](/itaa-1997/s995-1#s995-1-franking-period) (the longer period), then, for the purposes of subsection (1), each period within that longer period during which the entity is a former exempting entity is taken to be a franking period.
