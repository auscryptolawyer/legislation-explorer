# 104-170  Trust stops being a resident trust: CGT event I2


<a id="s104-170-1"></a>
**(1)**  CGT event I2 happens if a trust stops being a [[*resident trust for CGT purposes*](/itaa-1997/s995-1#s995-1-resident-trust-for-cgt-purposes)*](/itaa-1997/s995-1#s995-1-resident-trust-for-cgt-purposes).

<a id="s104-170-2"></a>
**(2)**  The time of the event is when the trust stops being one.

<a id="s104-170-3"></a>
**(3)**  The trustee needs to work out if it has made a [[*capital gain*](/itaa-1997/s995-1#s995-1-capital-gain)*](/itaa-1997/s995-1#s995-1-capital-gain) or a [[*capital loss*](/itaa-1997/s995-1#s995-1-capital-loss)*](/itaa-1997/s995-1#s995-1-capital-loss) for each [[*CGT asset*](/itaa-1997/s995-1#s995-1-cgt-asset)*](/itaa-1997/s995-1#s995-1-cgt-asset) that it owned (in the capacity as trustee of the trust) just before the time of the event except one that is [[*taxable Australian property*](/itaa-1997/s995-1#s995-1-taxable-australian-property)*](/itaa-1997/s995-1#s995-1-taxable-australian-property):

> <a id="s104-170-3-a"></a>
> **(a)**  covered by item 1 or 3 of the table in section 855-15; or

> <a id="s104-170-3-b"></a>
> **(b)**  covered by item 4 of that table because it is an option or right to [[*acquire*](/itaa-1997/s995-1#s995-1-acquire)*](/itaa-1997/s995-1#s995-1-acquire) a [[*CGT asset*](/itaa-1997/s995-1#s995-1-cgt-asset)*](/itaa-1997/s995-1#s995-1-cgt-asset) covered by item 1 or 3 of that table.

<a id="s104-170-4"></a>
**(4)**  The trustee makes a capital gain if the *market value of the asset (at the time of the event) is more than the asset’s [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base. The trustee makes a capital loss if that market value is less than the asset’s *reduced cost base. (4A) If the asset is an *indirect Australian real property interest, or an option or right to acquire such an interest, this Part and Part 3-3 apply to the asset as if the first element of the [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base and *reduced cost base of the asset (just after the time of the event) were its *market value at the time of the event. (4B) Subsection (4A) does not apply if the [[*capital gain*](/itaa-1997/s995-1#s995-1-capital-gain)*](/itaa-1997/s995-1#s995-1-capital-gain) or [[*capital loss*](/itaa-1997/s995-1#s995-1-capital-loss)*](/itaa-1997/s995-1#s995-1-capital-loss) the trustee makes is disregarded under subsection (5). <a id="s104-170-5"></a>
**(5)**  A [[*capital gain*](/itaa-1997/s995-1#s995-1-capital-gain)*](/itaa-1997/s995-1#s995-1-capital-gain) or [[*capital loss*](/itaa-1997/s995-1#s995-1-capital-loss)*](/itaa-1997/s995-1#s995-1-capital-loss) the trustee makes is disregarded if it *acquired the asset before 20 September 1985.
