# 112-25  Split, changed or merged assets

Split or changed assets

<a id="s112-25-1"></a>
**(1)**  This section sets out what happens if: Income Tax Assessment Act 1997                            311 Authorised Version C2026C00122 registered 10/04/2026

> <a id="s112-25-1-a"></a>
> **(a)**  a [[*CGT asset*](/itaa-1997/s995-1#s995-1-cgt-asset)*](/itaa-1997/s995-1#s995-1-cgt-asset) (the original asset) is split into 2 or more assets (the new assets); or

> <a id="s112-25-1-b"></a>
> **(b)**  a [[*CGT asset*](/itaa-1997/s995-1#s995-1-cgt-asset)*](/itaa-1997/s995-1#s995-1-cgt-asset) (also the original asset) changes in whole or in part into an asset (also the new asset) of a different nature; and you are the beneficial owner of the original asset and each new asset.

> *[[*Example*](/itaa-1997/s995-1#s995-1-example)*](/itaa-1997/s995-1#s995-1-example):** You subdivide a block of land into 3 separate blocks. Each of those blocks is a new asset.

<a id="s112-25-2"></a>
**(2)**  The splitting or change is not a [[*CGT event*](/itaa-1997/s995-1#s995-1-cgt-event)*](/itaa-1997/s995-1#s995-1-cgt-event).

<a id="s112-25-3"></a>
**(3)**  You work out the [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base and *reduced cost base of each new asset as follows: Method statement Step 1.    Work out each element of the [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base and *reduced cost base of the original asset at the time of the event referred to in subsection (1). Step 2.    Apportion in a reasonable way each element to each new asset. The result is each corresponding element of the new asset’s [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base and *reduced cost base. Merged assets

<a id="s112-25-4"></a>
**(4)**  If 2 or more [[*CGT assets*](/itaa-1997/s995-1#s995-1-cgt-asset)*](/itaa-1997/s995-1#s995-1-cgt-asset) (the original assets) are merged into a single asset (the new asset) and you are the beneficial owner of the original assets and the new asset:

> <a id="s112-25-4-a"></a>
> **(a)**  the merger is not a [[*CGT event*](/itaa-1997/s995-1#s995-1-cgt-event)*](/itaa-1997/s995-1#s995-1-cgt-event); and

> <a id="s112-25-4-b"></a>
> **(b)**  each element of the [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base and *reduced cost base of the new asset (at the time of the merging) is the sum of the corresponding elements of each original asset. 312                                 Income Tax Assessment Act 1997 Authorised Version C2026C00122 registered 10/04/2026 Specialist liability rules Chapter 3 Capital gains and losses: general topics Part 3-1 Modifications to cost base and reduced cost base Division 112 Section 112-30
