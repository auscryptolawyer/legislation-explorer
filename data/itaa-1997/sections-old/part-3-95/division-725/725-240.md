# 725-240  CGT consequences; meaning of adjustable value


<a id="s725-240-1"></a>
**(1)**  The CGT consequences for you of a [[*direct value shift*](/itaa-1997/s995-1#s995-1-direct-value-shift)*](/itaa-1997/s995-1#s995-1-direct-value-shift) are of one or more of these 3 kinds: Income Tax Assessment Act 1997                              25 Authorised Version C2026C00122 registered 10/04/2026

> <a id="s725-240-1-a"></a>
> **(a)**  there are one or more *taxing events generating a gain for [[*down interests*](/itaa-1997/s995-1#s995-1-down-interest)*](/itaa-1997/s995-1#s995-1-down-interest) of which you are an affected owner (see subsection (2));

> <a id="s725-240-1-b"></a>
> **(b)**  the [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base and *reduced cost base of down interests of which you are an [[*affected owner*](/itaa-1997/s995-1#s995-1-affected-owner)*](/itaa-1997/s995-1#s995-1-affected-owner) are reduced (see subsection (3));

> <a id="s725-240-1-c"></a>
> **(c)**  the cost base and reduced cost base of [[*up interests*](/itaa-1997/s995-1#s995-1-up-interest)*](/itaa-1997/s995-1#s995-1-up-interest) of which you are an affected owner are uplifted (see subsection (4)).

> **Note:** If there is a taxing event generating a gain, CGT event K8 happens. See section 104-250. Taxing event generating a gain

<a id="s725-240-2"></a>
**(2)**  To work out:

> <a id="s725-240-2-a"></a>
> **(a)**  whether under the table in section 725-245 there is a [[*taxing event generating a gain*](/itaa-1997/s995-1#s995-1-taxing-event-generating-a-gain)*](/itaa-1997/s995-1#s995-1-taxing-event-generating-a-gain) for you on a [[*down interest*](/itaa-1997/s995-1#s995-1-down-interest)*](/itaa-1997/s995-1#s995-1-down-interest); and

> <a id="s725-240-2-b"></a>
> **(b)**  if so, the amount of the gain; assume that the adjustable value from time to time of that or any other [[*equity or loan interest*](/itaa-1997/s995-1#s995-1-equity-or-loan-interest)*](/itaa-1997/s995-1#s995-1-equity-or-loan-interest) in the *target entity is its [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base.

> **Note:** For example, for that purpose the question whether the interest has a pre-shift gain or a pre-shift loss is determined on the basis that the interest’s adjustable value is its cost base. Reduction or uplift of cost base and reduced cost base

<a id="s725-240-3"></a>
**(3)**  The [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base and the *reduced cost base of a [[*down interest*](/itaa-1997/s995-1#s995-1-down-interest)*](/itaa-1997/s995-1#s995-1-down-interest) are reduced at the *decrease time to the extent that section 725-250 provides for the [[*adjustable value*](/itaa-1997/s995-1#s995-1-adjustable-value)*](/itaa-1997/s995-1#s995-1-adjustable-value) of the interest to be reduced.

<a id="s725-240-4"></a>
**(4)**  The [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base and the *reduced cost base of an [[*up interest*](/itaa-1997/s995-1#s995-1-up-interest)*](/itaa-1997/s995-1#s995-1-up-interest) are uplifted at the *increase time to the extent that section 725-250 provides for the [[*adjustable value*](/itaa-1997/s995-1#s995-1-adjustable-value)*](/itaa-1997/s995-1#s995-1-adjustable-value) of the interest to be uplifted.

<a id="s725-240-5"></a>
**(5)**  However, the [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base or *reduced cost base is uplifted only to the extent that the amount of the uplift is still reflected in the *market value of the interest when a later [[*CGT event*](/itaa-1997/s995-1#s995-1-cgt-event)*](/itaa-1997/s995-1#s995-1-cgt-event) happens to the interest. 26                                   Income Tax Assessment Act 1997 Authorised Version C2026C00122 registered 10/04/2026 Specialist liability rules Chapter 3 Value shifting Part 3-95 Direct value shifting affecting interests in companies and trusts Division 725 Section 725-245

<a id="s725-240-6"></a>
**(6)**  To work out:

> <a id="s725-240-6-a"></a>
> **(a)**  whether the [[*cost*](/itaa-1997/s995-1#s995-1-cost)*](/itaa-1997/s995-1#s995-1-cost) base or *reduced cost base of the interest is reduced or uplifted; and

> <a id="s725-240-6-b"></a>
> **(b)**  if so, by how much; assume that:

> <a id="s725-240-6-c"></a>
> **(c)**  the adjustable value from time to time of that or any other [[*equity or loan interest*](/itaa-1997/s995-1#s995-1-equity-or-loan-interest)*](/itaa-1997/s995-1#s995-1-equity-or-loan-interest) in the *target entity is its cost base or reduced cost base, as appropriate; and

> <a id="s725-240-6-d"></a>
> **(d)**  if the interest is an [[*up interest*](/itaa-1997/s995-1#s995-1-up-interest)*](/itaa-1997/s995-1#s995-1-up-interest) because it was issued at a [[*discount*](/itaa-1997/s995-1#s995-1-discount)*](/itaa-1997/s995-1#s995-1-discount)—the adjustable value of the interest immediately before it was issued was its cost base or reduced cost base, as appropriate, when it was issued.

> **Note:** For example, for that purpose the question whether the interest has a pre-shift gain or a pre-shift loss is determined on the basis that the interest’s adjustable value is its cost base or reduced cost base, as appropriate. Reductions and uplifts also apply to pre-CGT assets

<a id="s725-240-7"></a>
**(7)**  A reduction or uplift occurs regardless of whether the entity that owns the interest *acquired it before, on or after 20 September 1985.
