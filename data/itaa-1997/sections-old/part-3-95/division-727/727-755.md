# 727-755  Consequences of indirect value shift


<a id="s727-755-1"></a>
**(1)**  This Subdivision sets out the adjustable value method of working out the consequences (if any) of an [[*indirect value shift*](/itaa-1997/s995-1#s995-1-indirect-value-shift)*](/itaa-1997/s995-1#s995-1-indirect-value-shift).

<a id="s727-755-2"></a>
**(2)**  If those consequences are to be worked out using that method:

> <a id="s727-755-2-a"></a>
> **(a)**  the [[*adjustable value*](/itaa-1997/s995-1#s995-1-adjustable-value)*](/itaa-1997/s995-1#s995-1-adjustable-value) of each [[*affected interest*](/itaa-1997/s995-1#s995-1-affected-interest)*](/itaa-1997/s995-1#s995-1-affected-interest) in the *losing entity is reduced as provided in this Subdivision; and

> <a id="s727-755-2-b"></a>
> **(b)**  if the *gaining entity is a company or trust (except one listed in section 727-125 (about superannuation entities)) immediately before the [[*IVS time*](/itaa-1997/s995-1#s995-1-ivs-time)*](/itaa-1997/s995-1#s995-1-ivs-time), the [[*adjustable value*](/itaa-1997/s995-1#s995-1-adjustable-value)*](/itaa-1997/s995-1#s995-1-adjustable-value) of each [[*affected interest*](/itaa-1997/s995-1#s995-1-affected-interest)*](/itaa-1997/s995-1#s995-1-affected-interest) in the *gaining entity is uplifted as provided in this Subdivision.

<a id="s727-755-3"></a>
**(3)**  The consequences for the [[*affected interest*](/itaa-1997/s995-1#s995-1-affected-interest)*](/itaa-1997/s995-1#s995-1-affected-interest) depend on its character. There are consequences for the interest in its character as a [[*CGT asset*](/itaa-1997/s995-1#s995-1-cgt-asset)*](/itaa-1997/s995-1#s995-1-cgt-asset). However, if the interest is also [[*trading stock*](/itaa-1997/s995-1#s995-1-trading-stock)*](/itaa-1997/s995-1#s995-1-trading-stock) or a [[*revenue asset*](/itaa-1997/s995-1#s995-1-revenue-asset)*](/itaa-1997/s995-1#s995-1-revenue-asset), there are additional consequences for it in that character.
